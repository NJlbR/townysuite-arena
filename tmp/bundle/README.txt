========================================================
 TownyArchitecture Plugin v1.1.0 (Paper / Purpur / Spigot 1.20+)
========================================================

УСТАНОВКА НА СЕРВЕР:
1. Скопируйте файл TownyArchitecture-1.1.0.jar в папку /plugins вашего сервера.
2. Убедитесь, что установлены плагины Towny (0.98+) и AuraSkills.
3. Перезапустите сервер или выполните /plugman load TownyArchitecture.
4. В папке /plugins/TownyArchitecture/ будут созданы файлы config.yml и buildings.yml.

ОСНОВНЫЕ КОМАНДЫ ДЛЯ ИГРОКОВ И МЭРОВ:
/builds                - Открыть красивое интерактивное меню архитектуры города
/plot set build        - Назначить текущий чанк строительным участком города (только мэр)
/build info            - Подробный прогресс возведения здания на текущем чанке
/build repair          - Инструкция и список недостающих блоков для починки прочности
/build plot list       - Список всех размеченных строительных участков города
/build plot remove     - Снять статус строительного участка с текущего чанка
